# EriReborn · 安装系统

重装系统后的软件批量安装工具：WPF 图形启动器 + PowerShell 引擎 + 123 云盘分发。
全插件模式 —— 所有软件以"插件"描述，引擎统一执行 检测 → 下载 → 安装 → 复检 → 报告。

> 本仓库只包含**程序**本身。插件（`插件\*.json`）、清单运行时产物、缓存、日志、凭据
> 都不在仓库里；把 `插件\00-官方基础软件.json` 等插件文件放进 `E:\安装系统\插件\` 才有软件可用。

## 目录结构

```
安装系统\                       ← 运行根目录 (默认 E:\安装系统)
├── 启动器\
│   ├── src\                   ← C# WPF 源码 (csc 直编, 无需 MSBuild)
│   ├── build\build.ps1        ← 构建脚本 (自动同步 exe 到根目录)
│   ├── tools\webview2\        ← WebView2 托管组件 (绑定窗口用)
│   └── assets\
├── 引擎\
│   ├── 库\                    ← 公共库 (检测/云盘/插件解析/日志...)
│   ├── 生成基础插件.ps1        ← 完整名单 → 官方基础插件
│   ├── 生成目录.ps1            ← 插件+清单 → 软件目录.csv
│   ├── 导出状态.ps1            ← 全机状态 → JSON (给启动器)
│   ├── 安装软件.ps1            ← 统一软件安装入口
│   ├── 系统安装.ps1            ← 运行库流水线
│   ├── 驱动安装.ps1            ← WU 驱动 + 外设软件
│   ├── 安全清理.ps1            ← 本地导入安装
│   ├── 网盘登录.ps1 / 网盘凭据.ps1
│   └── 插件管理.ps1 / 取元数据.ps1
├── 清单\                      ← 数据源 (CSV + 完整名单.txt + winget_meta.json)
├── 插件\                      ← 插件 JSON (不在仓库里, 另行分发)
├── 缓存\ 日志\ 报告\           ← 运行时生成
└── 123云盘cookie.txt          ← 云盘登录态 (绝不入库)
```

## 构建

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File 启动器\build\build.ps1
```

需要 `tools\roslyn`（或 ModelInstaller 里的 csc.exe）与 .NET Framework 4.x。
构建成功后自动把 exe 同步到根目录 `SetupLauncher.exe`。

## 使用

1. 双击根目录 `SetupLauncher.exe`
2. 首次启动会询问是否绑定 123 云盘账号（绑定后自动下载云盘安装包；
   不绑定可打开分享页手动下载安装包，放入 `缓存\安装包`）
3. 「全部软件」勾选 → 「安装勾选项」；运行库驱动 / 安全清理 / 硬件 各有独立页

## 数据再生成（改了清单或名单后）

```powershell
引擎\生成基础插件.ps1          # 清单\完整名单.txt → 插件\00-官方基础软件.json
引擎\插件管理.ps1 -RefreshOnly # 插件\*.json → 清单\插件目录.csv
引擎\生成目录.ps1              # → 清单\软件目录.csv
```

启动器自检：`SetupLauncher.exe --selftest`（结果写入 `日志\启动器自检.txt`）。

## 注意事项

- 所有 `.ps1` 必须是 **UTF-8 with BOM**（PowerShell 5.1 无 BOM 会按 GBK 读中文导致语法错误）
- 123 云盘接口有严格限频（429），批量下载需要登录态且不要并发
- 凭据文件 `123云盘cookie.txt` 只存在本机，勿提交到任何仓库
